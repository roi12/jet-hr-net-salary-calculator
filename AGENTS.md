# UI implementation instructions

Before creating or modifying frontend components, read:

- `docs/DESIGN_SYSTEM.md`

All UI decisions must follow the documented tokens and patterns.

The screenshots under `references/jet-hr/screenshots/` are visual references
only and must never be imported, copied into `public/`, or displayed in the
application.

The SVG files under `public/brand/` are the only approved brand assets.

Prioritize:
- visual consistency;
- responsive behaviour;
- accessibility;
- clear gross-to-net explanations;
- reusable components.

Do not claim that the application is an official Jet HR product. Display:
“Unofficial prototype created for the Jet HR Product Builder technical task.”
